## Release gates and limits

- RAM extraction remains incomplete: fresh scan found 0/7 in the last run, stored verified material covers 6/7. Existing-account-key export proves a different path. The Windows method chooser is explicitly queued in [the fix list](v1.2-fix-list.md).
- Native macOS arm64 and Linux x64 runtime/key/real-DB acceptance requires their own runners. This Windows PC cannot establish it. macOS currently permits ad-hoc signing; that does not establish ordinary Gatekeeper acceptance or notarization.
- Live notification glass and long-duration real-account stability require further acceptance.

Earlier matched V1.1/V1.2 sampling (historical fixture, not accepted as this final comparison) found tray RAM 257 → 232.5 MB, idle CPU near the sampling floor, installer 1.24% smaller and popup creation 354 → 319 ms. Foreground RAM and full synthetic-glass CPU were higher; those earlier measurements do not prove improvement on all four axes for this final candidate.
