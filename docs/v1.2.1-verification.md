## Follow-up: account selection before key acquisition

The private Mac v1.2.0 report found a readable standard data root and account
databases, but no saved `myWxid`. Automatic account selection updates renderer
state; acquisition previously called the main process before persisting that
selection. The main process therefore could not resolve an account directory.
Acquisition now awaits saving the visible root and account, and stops if saving
fails. Eight regression cases cover empty/stale saved accounts, delayed writes,
failed writes, rejected IPC and incomplete selections.
Follow-up validation: both TypeScript projects passed; 125 unit test files
passed (1,714 tests passed, 8 skipped), plus 29 native/package regression tests.

This repairs the selection handoff on all desktop platforms. It does not resolve
macOS process-attachment denial. The private collector did not attempt attachment
or database decryption. The installed/package acceptance below predates this
follow-up; those results must not be treated as acceptance of an updated package.

## Scope and remaining limits

Private live-test profiles, exports and copied credentials were removed. Source
WeChat databases were read, not used for mutation tests. Receipts and fake-data
screenshots are retained outside the repository in the local final-audit folder.
Installation must independently back up the existing installation/profile, check
the registered path and single uninstall entry, compare installed EXE/ASAR/host
hashes against the fresh payload, and preserve protected profile hashes.

The first live format matrix had 53 media files in its first export versus 54
in subsequent formats. The later cold-profile matrix and repeat/corruption check
agreed on 54. Its original cause was not independently established; these checks
do not prove all source media are available or all cold-cache behavior is covered.

Unsigned Windows distribution/reputation, live desktop glass, day-long stability,
external connector delivery and every reporter-specific case remain unverified.
Real Mac WeChat login/key acquisition is deferred by the user. Prior ARM macOS 15
encrypted-fixture acceptance covers the imported fixes, not this new complete
commit. Mac/Linux final builds have not been rerun remotely because pushing is
not authorized. Native FTS acceptance remains separate from Reader's loaded-only
fallback. Windows no-login scanning stays disabled in V1.2.
