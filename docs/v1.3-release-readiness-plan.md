They demonstrate layout with fixtures, not native database acceptance.

Second-account acceptance, other WeChat versions and native Mac/Linux runtime testing are unavailable compatibility coverage. They do not block current Windows engineering. Windows scan exposure must retain explicit version/capability limits rather than imply support on untested combinations.
