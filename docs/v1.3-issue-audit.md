## Recommended next work, without waiting for unavailable machines

1. **Finish consistent media export controls and failure reporting (#40, #33, related #46).** Original-only must work outside Archive; add precise time windows and test repeated/cached exports, missing keys, absent files, voice/video/file outcomes and cancellation. Success means accurate artifacts and actionable explanations, not merely hiding the warning.
2. **Finish the storage default/migration story (#38).** Stop placing new application media caches under Documents by default; retain legacy user content, offer verified migration, and preserve the warning that a local path can still be synchronized.
3. **Improve connection diagnosis (#34/#36).** Export sanitized stage-specific evidence for the actual selected directory/account, native host, key representation and shard coverage. These changes and fixture tests do not need the reporter's machine; claiming their exact failure resolved does.
4. **Add Reader reply drafting with an existing WeClone (#45).** This is a bounded user-visible feature implementable on the present machine, with manual review/copy and no sending automation.
5. **Improve retrieval/evidence quality and release readiness.** Expand the bilingual labeled set beyond 24 retrieval queries/six instructed AI cases, address measured recall misses, check consistent behavior across Reader/Export/Archive, and prepare a reviewable Windows V1.3 change set and release notes after the selected fixes.

Other WeChat versions, another account and native Mac/Linux machines are **unavailable compatibility coverage, not prerequisites for continuing the actionable Windows work**. Keep unsupported combinations explicit and scan entrypoints gated as needed; do not keep rerunning warm scans or asking for hardware the user cannot provide. The current-account post-restart check is already complete. No Computer Use or desktop automation is proposed.
