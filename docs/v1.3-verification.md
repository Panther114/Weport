## Findings and repairs

1. **Search deadline bypass:** queries with no matches, or rows excluded by filters, could scan without reaching the deadline check. Check elapsed time every 1,024 scanned documents before filtering. The new deterministic-clock regression failed before the repair and passes afterward.
2. **Media-only export identity loss:** the native fast media stream could omit database/table provenance and narrow local IDs to JavaScript numbers. Real image export succeeded but its source identity did not match Reader. Reject the entire inexact fast-stream batch and use the existing canonical cursor collection. Three regressions cover missing provenance, a partly scoped batch, and an unsafe numeric ID; distinct shards sharing IDs and exact large IDs remain distinct.

No source-database mutation, host architecture change, scanner production enablement, installed-app replacement, version bump, commit, push or release was performed. The fresh unpacked package retains development version 1.2.2 on the V1.3 branch.
