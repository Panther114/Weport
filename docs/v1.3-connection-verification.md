Its exit status describes successful execution of the acceptance harness; inspect `existingKey.connectionReady` and `freshScan.connectionReady` separately for product readiness. Existing `WeFlow.exe` is accepted only when its hash exactly matches the packaged application executable; the probe neither overwrites nor removes an existing host. If absent, it creates and cleans its own temporary deployment using the established helper.
