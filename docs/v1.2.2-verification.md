## Limits

No paid/live model inference, real-account database writes, reporter-specific export reproduction, macOS/Linux runtime verification, installation or public release was performed. Language/conciseness are prompt policies with request-shape tests, not proof that every model will obey them. Native host initialization proves packaging, not successful export of a real account. This short benchmark does not establish day-long stability.
