Native asset verification passed for both. Issue #29 was closed after publication.

## Current implementation acceptance

- Electron desktop and portable packaging; no Tauri runtime or bridge.
- Offscreen startup, notification dimensions, readable glass previews and responsive pages.
- Exact Reader/Search/media/annotation identity, including shard and 64-bit IDs.
- Export recovery, portable manifests and integrity checks.
- V1.2 uses existing/manual keys and login capture. Deferred scan-based export must require full key coverage before V1.3 acceptance.
- Current scan-only coverage is 6/7 (one biz-message shard missing). Separate existing-account-key proofs open all 7 databases; current full-copy export/identity evidence is in [verification](v1.2-verification.md). Source server-ID collisions must remain distinct from cursor/export duplicates; no rows may be discarded by server ID alone.
- The official V1.2.0 NSIS is installed at `%LOCALAPPDATA%\Programs\Weport` (installed hashes match the published payload, protected profile hashes unchanged, one uninstall entry); Flash is a published/tested portable artifact, not an installed app.
- Four performance axes: background RAM, idle/notification CPU, installer bytes, and sampled peaks/growth. Keep synthetic-capture and short-soak limitations explicit.
