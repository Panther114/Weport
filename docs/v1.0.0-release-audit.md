# Weport v1.0.0 — 发布就绪审计

> 状态：**功能已冻结，等待人工验收**。本文记录本轮"整体 bug / UIUX 排查"覆盖了什么、
> 新发现了什么、以及**还没有覆盖**的范围。没有覆盖的部分不写成"已验证"。

## 本轮修掉的缺陷（都是实测定位，不是走查猜的）

### 1. 导出页的"偶尔抖一下" —— 真正的根因是**一次布局偏移**

用 `PerformanceObserver(type: 'layout-shift')` 抓浏览器自己判定的偏移，定位到两类：

| 来源 | 之前 | 现在 |
| --- | --- | --- |
| 进度行**从无到有**（吸顶块变高，把 `.export-layout` 整体推下去一次） | CLS 0.0158 | 0（永远占位） |
| 扫过动画用 `margin-left`（布局属性，每秒触发重排） | 累计 116 次 | 0（改 `transform`） |
| **合计 CLS** | **0.01797** | **0.00161**（仅剩 toast 自身出现，那是应有的反馈） |

这是本轮最有价值的一条：之前两轮都在"隔离重渲染 + 钉死几何"，方向对但没测到位 ——
真正的残余偏移来自**进度行出现的那一刻**，只有浏览器自己的 layout-shift 记录能抓到。

### 2. 防撤回列表「压紧」把行压塌了

把行高从 40px 压到 ~26px 时写了 `min-height: 0`，结果 192 行全部塌成 **3.3px**。

根因：`.anti-revoke-list` 是**定高** (`max-height: calc(100vh - 300px)`) 的 flex 列
容器，flex 子项默认 `flex-shrink: 1` —— 192 行被"平摊"进 350px。`min-height: 0` 正好
拆掉了最后一道防线。改为 `flex: 0 0 auto` 后单行 **25.3px**（原 40px，多显示约 37% 的行），
头像仍 22×22。

**这类"定高容器 + 默认可收缩子项"是个通病**，本轮的审计只覆盖了 `.anti-revoke-list`。

### 3. 主题模型：明暗与强调色被绑成 12 张组合卡片

点一个颜色会顺手把深浅改掉，「自定义」标题还跟着明暗变。已拆成两个独立轴
（「深浅」分段控件 + 6 个色块 + 第 7 个「自定义」）。

### 4. 通知玻璃：从"逐帧自适应"改成"一次成型"

逐帧自适应在回退路径上每秒写 6 个 CSS 变量、且采样率被玻璃帧率绑住（1.5Hz），
文字色一顿一顿。现在只在首批样本稳定或几何变化时解析一次。原生 D3D11 面板改为
默认开启（Chromium 采集在本机全灭，那条路的物理上限就是 ~3fps）。
实测：稳定后 **0 次变量写入**、60fps、0 长任务。

### 5. 文案与占位符的两类系统性缺陷

- **Markdown 语法漏进 JSX**：`**只保存在本机**` 在 JSX 里不渲染，用户看到字面星号。
  全仓扫了一遍，`src/**/*.tsx` 里剩下的 `**` 全在注释内（已核对）。
- **占位符不继承控件字体**：`::placeholder` 用的是 UA 默认字体（Arial），
  空输入框与填字后字形不一致。已全局 `font: inherit`，15 个文本控件比对通过。

### 6. 人格克隆：整体改为**纯本地**

数据不出本机 —— 删除服务器配置、上传、远端删除/可见性、服务器状态、本地服务
自动拉起、HTTP 聊天；新增 on-device 聊天（人格 MD + 本地 BM25 检索 + 用户自己的
模型）。新增 `ai/localRetrieval.ts`（24 个单测）。
实测：101,730 条消息 / 183 会话生成成功，检索命中 24 段、耗时 ~1s，回复语气正确。

顺带修掉三个只有真跑一遍才会暴露的问题：

- **地区限制**：默认的 OpenCode Go 返回 `This model is not available in your country.`
  —— 生成与聊天都加了"服务回落"到用户自己的默认服务。
- **瞬时断连**：`knowledge.md` 生成时 `fetch failed` 直接让整条生成失败。加了退避重试。
- **死功夫**：语料二审按 5% 抽样（16k 块 → 约 800 次模型调用），而它产出的补丁
  **只被上传路径消费** —— 上传删掉后这就是纯浪费，实测把生成从 2 分钟拖到小时级。
  已移除（语料入库时的本地正则脱敏仍在）。

生成改为**事务式**：先写临时目录，全部成功再原子换名，失败时旧克隆完好无损。

## 尚未覆盖（**不要当成已验证**）

1. **macOS / Linux 运行时行为** —— 本机无法执行。见 `docs/v1.0.0-unverified.md`。
2. **人格克隆的生成质量** —— 本轮验证的是"链路通、检索命中、语气对"，不是
   "分身像不像本人"的主观评分。上一轮量过字面相似度，本轮没重跑。
3. **"定高容器 + 可收缩子项"的全仓排查** —— 本轮只修了 `.anti-revoke-list`。
   同类结构（会话列表、分析页侧栏、设置页长列表）**没有逐个量过**。
4. **导出真实大库** —— 进度条的位移是用真实 IPC 负载灌的，但没跑一次完整的大库导出
   （189 个会话）去对比耗时与内存峰值。
5. **原生玻璃在别的 GPU / 驱动上** —— 本机实测正常（卡片亮度 236.7、读的是桌面），
   但 `WEPORT_NATIVE_GLASS=0` 之外的失败组合没有实测样本。
6. **无障碍** —— 只做了"高频区域不挂 aria-live"这一项，没有用读屏实际走一遍。
7. **i18n** —— 界面全中文，没有做多语言核对。

## 建议的验收顺序

1. 打开通知（应看到实时玻璃跟随桌面；文字可读）
2. 导出 → 观察进度行不推动其它元素、完成后显示「导出完成 189/189」
3. 防撤回 → 行更密、头像不变形
4. 设置 → 外观 → 换颜色不应改变深浅；自定义色板随深浅给两套
5. 设置 → 外观 → 背景遮罩拉到 100%，明暗各看一次（浅色应仍是浅底深字）
6. 人格克隆 → 开始对话（本机检索 + 你的模型）
