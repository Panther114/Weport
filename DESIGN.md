# Weport DESIGN

## Mode
Operate — task-first export console.

## Thesis
One compact export instrument: locate WeChat data, pick format, dump every chat.

## Visual world
- Midnight graphite surfaces (`#0b0d11` → `#1a1f2a`)
- Single amber signal accent (`#e8a23a`)
- System UI type (Segoe UI Variable) for native Windows density
- Mono for paths only
- Tight 12–16px panel radius, instrument spacing, no card nests

## Signature
Amber progress bar + live session name as the export “meter.”

## Layout
Fixed-width compact window (~440×700). Three panels: data, account, export. Primary action pinned in footer.
